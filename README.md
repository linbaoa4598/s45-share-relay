# S45 Share Relay

原项目 S45 共享协议的网页查看器与 TCP → WebSocket 中转。不是 S44 移植版协议。
无第三方 npm 依赖，Node.js 22+；Docker 使用 Node.js 24。

## 本地运行

```sh
npm test
npm start
```

浏览器访问 http://127.0.0.1:8888；TCP 默认 9999。
默认仅监听本机。如需可信局域网使用，设置 HOST=0.0.0.0。

## Railway 部署

1. Railway 新建服务，选择此 GitHub 仓库；Dockerfile、railway.json 会配置构建与健康检查。
2. **第一次部署前**在 Variables 设置：
   - WEB_USER：建议保留 viewer
   - WEB_PASSWORD：自己设置至少 16 字符的独立密码，绝不能提交到 GitHub。
   - TCP_PORT：9999
   - HOST：0.0.0.0
3. Deploy 后生成 HTTP Public Domain。程序读取 Railway 的 PORT，网页自动使用同域 WSS。
4. 在 Networking 添加 **TCP Proxy**，内部目标端口填写 9999。
5. 手机原项目配置中的“共享服务器”填写 Railway 分配的 TCP 代理域名，
   “共享端口”填写分配的**外部代理端口**，不是网页域名/443，也通常不是9999。
6. 浏览器打开 HTTPS 公网域名，在浏览器登录提示中输入 WEB_USER/WEB_PASSWORD，再输入六位房间号。

仅部署**一个区域、一个实例**。房间保存在进程内存，多副本无法同步；
发布更新会暂时断流，浏览器会自动重连，房间须等待手机重新上传。
不要启用 Serverless/休眠，以免长连接被挂起。
生产环境缺少合格 WEB_PASSWORD 时程序拒绝启动，这是预期安全检查。
/healthz 是不含对局数据的公开健康端点。
访问密码保护网页、资源和 WebSocket；手机旧 TCP 协议没有认证能力。

原始项目配置键：

```ini
共享服务器=<Railway TCP代理域名>
共享端口=<Railway TCP代理外部端口>
共享频率=20
共享输出宽度=2400
共享重连间隔=2000
```

不要使用 S44 移植版的 ShareLoad 配置方式。
原程序的解析器是否支持代理域名需真机验证；重建 UI 的连接入口目前只接受数字 IPv4。
不要把 DNS 解析得到的临时地址当成长期固定 IP。

文档：[TCP Proxy](https://docs.railway.com/networking/tcp-proxy)、
[Healthchecks](https://docs.railway.com/deployments/healthchecks)。

## 协议与限制

```text
gameData<六位数字房间>[==][==]<人物>---<野怪>---<兵线>
```

- 三组分别 9 / 5 / 3 列，逗号分列，== 结束一条记录。没有第四个阵营段。
- TCP 没有消息长度或结束符。中转以**下一帧头**划分上一帧，通常延迟一帧；
  只有一帧且连接不断开时不会猜测边界。正常 EOF 尝试提交最后完整帧。
- 人物 F9 不认定为阵营，F4/F5/F8/F9 保留原始数字，不猜测 CD 单位。
- 野怪显示原始 F2/F3；兵线按实际上传绘制，不套用 S44 的固定 70 或缺兵线假设。
- 人物/野怪地图边长按“共享输出宽度 / 11.2 × 1.455”转换；
  人物中心补回原头像坐标减去的20像素。各组偏移可在网页独立校准。
- 兵线缓存比例未完成真机验证，不能保证其初始边长正确。
- 网页3秒无更新清除标记，房间10秒无更新移除；断线2秒后重连。
- 当前还原工程没有把采集结果自动接入共享打包，手工共享入口与原始 ELF 是不同验证对象。
- 单元测试与回环测试不代表原始程序、手机真实对局或 Railway 云端验证成功。

## 公网风险

**网页登录不保护原始 TCP 上传端。** 旧协议无认证、无加密，第三方可能注入相同房间数据。
六位房间号不是密码；不要传输敏感数据。若需要可靠的公网上传身份认证，应先修改手机
发送端和中转协议，或使用受控隧道/网络访问限制。本项目不假装解决旧协议缺失的认证。

本仓库仅包含部署所需网页、中转、测试与配置，不包含原始 ELF、逆向资料、授权卡密、
本地备份或测试二进制。没有声明对第三方地图素材授予新的许可。
